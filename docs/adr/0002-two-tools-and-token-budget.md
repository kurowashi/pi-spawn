# 0002. ツールは2本。モデルに見せる面を予算で拘束する

## 状態

採用(Step 1)

## 文脈

`pi-subagents` の `subagent` ツールは description 5,240 文字、parameters 12,985 文字(トップレベル
82 プロパティ)、管理アクション49種。ツール定義は毎リクエスト送られるため、これは恒久的な文脈税である。
upstream は 0.71.0 で遅延ロード用の `subagents_enable` を追加したが、これは膨らんだ面を隠す対症療法で、
有効化後は同じコストを払う。

## 決定

モデルに見せるツールを `spawn_agent`(親のみ)と `message_agent`(親と子)の2本に固定し、
description とパラメータスキーマの合計をトークン換算して予算で拘束する。

- 予算: 400 トークン(実測 267)。説明文の言い回し変更では壊れず、ツール追加や引数群の追加では落ちる幅。
- 副次的な効果として、遅延ロード機構が不要になる。予算テストが同じ役割を果たすため、機能を1つ消せる。

## 結果

- `subagent` 比でツール面は約 95% 減(約 5,000 → 267 トークン)。
- ツールを増やす/引数を増やす変更は、必ず予算テストの更新を伴う。予算は黙って上げられない。
- 子は `spawn_agent` を受け取らないため、委譲の深さが 1 に固定される(副次的な安全境界)。
